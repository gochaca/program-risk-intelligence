# AI Portfolio

A collection of AI tools I've built from scratch to solve problems I encountered directly in program and vendor management roles. Each project is documented end-to-end: problem statement, design decisions, and evaluation against realistic mock data.

## Projects

- [`01-program-risk-intelligence/`](./01-program-risk-intelligence/) — **Program Risk & Vendor Coordination Intelligence.** Ingests weekly status updates from multiple teams/vendors, classifies risk with a stated reason, flags cross-team patterns a single update wouldn't reveal, and auto-drafts status reports at team and executive altitude.
